# HIGHFLY SKIN3 — Mobile playtest preparation (read-only branch)

## Why it matters
Phase 10 was GREEN in a **desktop** Chromium window. HIGHFLY must feel easy
to use on an actual Samsung S23 Ultra in landscape. This step creates a
*separate* source-real preview candidate from Phase 10. It does not change
the green phase10 prototype, the real HIGHFLY game, PF-6, SKILL5 or the
older separate Skin Factory V2 branch.

## User playtest V1 (no full gameplay)
- Original male and female Hunter body / Rig_Medium and the seven official
  armor families, no third-party substitute character.
- The pilot uses verified real item identifiers, but maps them to the
  ORIGINAL kit's chest/legs/feet as a **cosmetic preview**, not the item's
  unique unseen 3D model.
- Tap an item to equip; see visible original mesh change on the authentic
  body; tap an equipment slot to remove; switch gender without losing gear.
- Save / load **sandbox localStorage**; browser reload; source-only original
  animation options, turntable and advanced seven-slot dressing.
- Simple controls are on top, advanced inspector collapsed initially.
- Emulated landscape viewport and touch; portrait fallback.
- There is NO custom premium original skin authoring in this pilot yet.
- Held sword model is not certified: the object can equip in the pilot state
  but a real weapon attached to a native hand/back requires an additional gate.
- Source-only lab save is NOT PF6 gameplay inventory/save.

## Public delivery contract
The prior Skin Lab V2 branch explicitly forbids publishing Skin Lab by
overwriting the game's GitHub Pages artifact. Respect the separation.
A public lab playtest URL requires a **dedicated site/repository** with
appropriate original third-party asset rights, stable origin,
HTTPS, offline/browser storage review and mobile acceptance. No fake live URL.

## Actual-device acceptance
Emulated browser GREEN is not a physical S23 Ultra performance pass.
Human tester should see the model (not boxes), rotate and move camera,
tap all buttons in landscape, equip/unequip, switch male/female, save,
reload and report lag, clipping, screenshots, blank preview or crashes.
