- Create a NEW original skin in each approved commission, based on natural text, image, or both.
- ClaudeCraft/Paladin/HF7RF are anatomy, joint, weight transfer, animation and attachment references only.
- Do **not** deform existing armor or recolor it and call it a new design.
- The previous SKIN9-B Royal Dark test is art REJECTED; retain it as negative test only.
- Three.js is the preview renderer. Blender or a licensed original-geometry authoring engine builds GLB. Unity consumes the approved resulting skinned GLB.
- A live static browser cannot safely run authenticated AI inference and Blender. Implement a separate authenticated backend/queued modeling job, or have assistant operate the GitHub/Blender workflow with explicit user designs.
- No user images are transmitted by this new HTML page; local image inspection computes SHA-256, dimensions and a color sample. **Semantic analysis of uploaded images by AI is not connected yet**.
- A technical GREEN means schema and gating pass, not a finished generated model. All output commissions have autoGenerated3D=false until a separate validated artifact exists.
- Signed AI concept attestation + original mesh provenance + human visual approval required. Do not expose API keys in Vercel client JS.
- Rules and tests here are independent of the SKIN 7–10 editor. They do not replace public HIGHFLY Pages or SKIN 3.
